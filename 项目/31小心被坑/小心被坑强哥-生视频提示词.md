## 四、翻车修复

| 现象 | 处理 |
| --- | --- |
| 面瘫 / 不眨眼 | 总述或分 beat 补 **自然眨眼每 3～5 秒** |
| 出现字幕 / 花字 | 首行 **禁止字幕** · 重出 |
| 出现背景音乐 | 首行 **禁止背景音乐** · 重出 |
| 预警不够严肃 | 重写 **0～2.5s** · 竖食指 + 眉心微蹙 + 「小心被坑」加重 |
| 否定段像念稿 | 重写 **2.5～4.8s** · 「装修公司」「熟人」分摇手 + 嫌弃表情 |
| 全拆全改没摇手 | 重写 **4.8～6.3s** · 拍胸后 **再摇手否定** |
| 省一半没手势 | 重写 **6.3～8.0s** · **劈半或比五** |
| 厨卫报项不指 | 重写 **9.3～12.0s** · 左指全屋 + **竖指厨房厕所** |
| 强哥变普通话 | @音频1 补 **成都温江四川话** · 加 **强哥口播：四川话男声** · 写 **禁止普通话念稿** · 重出 |
| 背景太新不像老房 | 重写 @图片1 绑定 · 补 **旧墙皮旧砖旧门洞** |
| Logo 糊/缺字 | 重写 @图片3 绑定 · 左胸「大改造家」可读 |
| 三脚架广告感 | 总述补 **手持微晃呼吸感** · 禁止三脚架 |
| 口播超时 | 已 **92字**；仍超时则优先压「不管是」为「不管」或合并「周边区县」 |
