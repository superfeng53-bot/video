### 点球破门 · 球路空间锁 & 防穿模（`[H]` · 格 1 必读）

**症状**：球从侧面/边网「穿模」入网，而非正面破门。  
**根因**：① 参考图为侧俯争顶，模型抄了横向球路；② Reverse-angle 段 `Whip pan` 与 Net-cam 同段混写，空间轴断裂；③ 未写清「球必须穿过球门正面矩形框」。


| 铁律                         | 执行                                                                        |
| -------------------------- | ------------------------------------------------------------------------- |
| **进攻轴**                    | 罚球点 → 球门正中 → 球网，三点一线；所有球场机位站**同一进攻轴侧**，禁止越轴                               |
| **球路**                     | 低平或半高直线球；从罚球点**沿深度轴**射向球门正中；球**只从两根门柱之间、横梁下**进入                           |
| **Reverse-angle（0–0.50s）** | 主罚者身后 Pitch-level；助跑 **Dolly push-in** 缓推；竖屏罚球点下、球门上；**禁止 Whip pan**；击球即止 |
| **硬切点**                    | **0.50s** 脚触球后 **立即硬切** Goal-line Net-cam，不在同一镜头内横跟球                      |
| **Net-cam（0.50–1.2s）**     | 球网内后角固定 POV（门线/门将压力角）；球沿纵深**正面飞来**；0.65s 撞网                               |
| **参考图 {{Mixed 4}}**        | **仅取环境**（草皮/围挡/光照）；**禁止**抄侧俯争顶构图与横向球路                                     |


**若仍穿模 · 生成策略（按优先级）**  

1. **拆段生成**：先单独做 **0–1.2s 点球入网** 2 秒短片，满意后再拼 14s 或作故事板格 1 定帧。
2. **故事板格 1** 线稿须画清：罚球点→球门中轴箭头、门柱门框矩形、球从正面入网。
3. **一镜一运镜**：Reverse-angle 段只 Dolly push-in；跟球只交给 Net-cam 硬切段。
4. 有 Motion Brush 时：**只涂抹球从罚球点指向球门中心的轨迹**，不涂横向。
5. 用**正面球门入网**短视频作参考（如有），不用侧面进球素材。

### 球场→客厅 · 两切一桥（`[H]` · 撰写用）

**问题**：4.5s 起若一镜从草皮滑到客厅，Seedance 易背景 morph、转播感与家装感糊成一团；若每过门框就切，又会闪切疲劳。  
**解法**：球场→客厅只用 **2 次遮挡切**，中间用 **通道桥接镜** 稳住空间，客厅内 **一镜跟到底**。


| 镜号    | 时段       | 空间     | 镜头时长        | 切否            | 声画动机                     |
| ----- | -------- | ------ | ----------- | ------------- | ------------------------ |
| **A** | 4.5–5.5s | 球场边线末段 | 1.0s        | 末 0.3s **切1** | 「滑出场了？」+ **0.25s 反转前静音** |
| **B** | 5.5–6.1s | 球员通道   | **0.6s 桥接** | 末 0.4s **切2** | 「原来是…房子去了」起声 · 建立室内通道感   |
| **C** | 6.1–8.5s | 客厅→指阳台 | **2.4s 一镜** | **不切**        | 「看这客厅，真亮堂！」完整展示          |


**丝滑三件套**


| 手段       | 切1 球场→通道                    | 切2 通道→客厅                   |
| -------- | --------------------------- | -------------------------- |
| **遮挡物**  | 白色边线 + 深蓝广告板自下而上擦满镜头        | 通道尽头门框从右向左横擦满镜头            |
| **动作连续** | 同一跪滑方向、膝高、人物框 ±8%、后倾角、速度不跳变 | 切前膝盖即将过门槛 → 切后同一膝盖已在客厅浅色地砖 |
| **光线桥**  | 球场日光 → 通道顶灯暖暗收束             | 门框擦过后客厅大窗亮部爆发（叠「真亮堂」）      |


**切镜铁律（4.5–8.5s）**

- 只切 **2 次**，通道内、客厅内各 **禁止再加切**
- 每次遮挡 **0.3–0.4s**，藏在前景擦镜里，禁止 dissolve / 背景渐变
- 桥接镜 B 不少于 **0.5s**，让观众先接受「滑出球场进通道」，再进客厅
- 镜 C 从进客厅到指阳台 **一镜跟拍**，给家装卖点留足停留
