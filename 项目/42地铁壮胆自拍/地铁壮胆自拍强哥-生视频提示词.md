## 三、翻车修复

| 现象 | 处理 |
| --- | --- |
| 开头乘客已经看强哥 | 强化首秒前半段：所有乘客看手机、窗外或前方，喊出前无人看他 |
| 全车同时机械转头 | 强化「仅附近4～6人、先近后远、自然错峰反应」 |
| 没人对「嘿」作反应 | 把0～1秒独立重做，锁定「嘿落下后抬头或转脸」 |
| 乘客一起喊或抢台词 | 强化乘客全程嘴闭，仅强哥出声 |
| 强哥和乘客有眼神互动 | 强化眼睛全程锁手机镜头、头部朝向镜头、手势只在自己胸前 |
| 背景乘客一直保持同一状态 | 固定三类节奏：一人听完、一人看一眼低头、一人中段才抬头 |
| 画面变成第三人称跟拍 | 强化强哥右手高举手机、前置自拍、高于双眼25～35厘米 |
| 强哥表现拘谨 | 强化开头快速吸气壮胆，随后越讲越兴奋、手势砸实、洪亮带笑 |
| 自拍晃动过大 | 保持肘部贴近身体，只有地铁运行与呼吸造成的小幅自然晃动 |
| 口播超时 | 按分句时间点重出；主句稳定约5.3～5.5个发音字/秒，不增加语气词或停顿 |
| 结尾停住形成落版 | 强化14.50秒最后一字结束即屈肘放手机，15秒截在下降中途 |
