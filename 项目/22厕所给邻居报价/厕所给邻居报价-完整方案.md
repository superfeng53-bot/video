## 二、背景怎么选（厕所 vs 厨房）

### 2.1 定稿：**已翻新卫生间** · 不用厨房

| 方案 | 结论 | 原因 |
| --- | --- | --- |
| **已翻新卫生间** | ✅ **定稿** | 台词「卫生间」「装一个厕所」；视觉证据 = 新砖 + 马桶 + 淋浴 |
| 待翻新卫生间 | ✗ | 与「没花好多钱就改巴适咯」矛盾 |
| 厨房 | ✗ | 声画错位 |
| 豪华样板间 | ✗ | 「没花好多钱」不可信 |

### 2.2 环境参考图 @图片1 必含元素

| 必见 | 作用 |
| --- | --- |
| **新墙地砖** | 「改好了」证据 |
| **新马桶 + 浴室柜** 或可见其一 | 卫生间可读 |
| **淋浴隔断 / 淋浴头** 一角 | 扣场景 |
| 顶灯均匀、无杂物 | 真实温江户改感 |

### 2.3 实拍建议

- 刚完工已保洁一间卫；**门框外 POV** 向内，**门框全开**  
- 起幅门内仅强哥检查；邻居约 1.5s 闯入 **停门口**

## 三、POV 站位（`[H]`）

### 3.1 空间分区（9:16 · 门框全开向内）

```
        走廊侧（拍摄者·画外音 POV）
          │
┌─────────┴─────────────────┐ 9:16 门框全开·门扇不挡
│ [门内·新砖马桶淋浴·纵深]      │
│              强哥 ● 偏右上   │  门内中远景
│                             │
│ 邻居 ○ 站门槛外              │  前景·朝门内看强哥
│═════════════════════════════│  门槛线
│ 📱 镜头（画外音·不入画）      │
└─────────────────────────────┘
```

| 角色 | 声画 | 脚点 / 视线 |
| --- | --- | --- |
| **画外音** | **仅画外音** · 永不出画 | 持机 POV；0～3s 安利段出声 |
| **强哥** | 入画 · **仅门内** | 偏右上中远景；俯身检查→起身→对镜头口播 |
| **邻居** | 入画 · **仅门口** | 门槛外前景朝门内；7～9.5s **先对画外拍摄者（面向镜头、不对视镜头）、再转强哥** 两拍 |

**铁律**：门框全开 · 邻居全程门口不入厕 · 强哥仅门内 · 画外音永不出画。

### 3.2 起幅动线

1. **0s**：门框全开 POV，门内强哥俯身检查，嘴闭  
2. **约 1.5s**：邻居闯入停门口，嘴闭  
3. **0～3s**：画外音安利  
4. **3～6s**：强哥起身；邻居问价  
5. **6～7s**：强哥「不贵的，」  
6. **7～9.5s**：邻居先 **转向镜头方向、视线偏过镜头对画外拍摄者**（不对视镜头）说「这么便宜」→ 再 **转头朝门内强哥** 说「强哥快去给我弄！」  
7. **9.5～15s**：强哥「要的，」→ 包工包料 + CTA

### 3.3 轴线

- 主轴线：门口邻居 — 门内强哥  
- 常态：前景邻居朝门内 + 右上远景强哥  
- 7～9.5s：邻居 **先对画外拍摄者后转强哥** 两拍（面向镜头、不对视镜头）；**每2-4秒自然眨眼一次**
