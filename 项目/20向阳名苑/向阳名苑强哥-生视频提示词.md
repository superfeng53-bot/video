## A · 编辑约束（给人 / 给 AI 改稿用｜❌ 不粘贴进即梦）

### 方法论

- 字节 Seed 官方：[Seedance 2.0 发布文](https://seed.bytedance.com/zh/blog/official-launch-of-seedance-2-0) — 多模态 @ 引用、方言口型、时序音画对齐
- 社区结构：CRAFT / 八层（素材→主体→动作→运镜→光影→音频→时序→约束）
- 运镜铁律：一镜一动、口型段 locked、主体动作与镜头运动分开写

### 改稿原则

| 维度 | 注意 |
| --- | --- |
| 结构 | 员工单独写全程段；强哥/车动作写入对应时段；强哥下车即开口 |
| 长度 | 控制在约 200–300 词等效；避免尾部重复护栏 |
| 动作词 | 避免「最快/全速/弹射」；用「硬跺奔走/推门跃出/蜂拥涌出」 |
| 气质 | 员工：古惑仔集结出动、成帮冲阵；强哥：黑老大压阵指挥，对镜段可略收戾气 |
| 人数 | 用「分波约 N 名」软计数，不硬写总人数 |
| 员工动线 | 右后侧拉门涌出→贴车身右侧朝车头→经强哥与右前车门空隙→绕车头→画面深处入口；不写静态画面区位 |
| 台词 | 五段台词锚点不删；强哥台词均在下车后；锚点约 0.80 / 2.50 / 6.50 / 10.50 / 13.00s |
| C 区禁写护栏 | 下列只作改稿备忘，**不粘贴进即梦**：面部一致/无变形；肢体连贯/避免抖动弯曲；一镜不切；仅强哥口型/队员嘴闭背侧对镜；口播对镜/指挥不对镜；拍胸仅限强哥拍自己左胸；禁止念稿脸 |
| C 区可写约束 | 【约束护栏】无字幕，无背景音乐 |

### 翻车重 roll 顺序
