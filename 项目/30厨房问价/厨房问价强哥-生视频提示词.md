## 四、翻车修复

| 现象 | 处理 |
| --- | --- |
| 面瘫 / 不眨眼 | 总述或分 beat 补 **自然眨眼每 3～5 秒** |
| 出现字幕 / 花字 | 首行 **禁止字幕** · 重出 |
| 出现背景音乐 | 首行 **禁止背景音乐** · 重出 |
| 李阿姨段强哥抢说 | 强调李阿姨段 **嘴闭量尺/倾听** |
| 叠说 | 李阿姨收句时强哥 **嘴闭** · 强哥接话时李阿姨 **不出画不出声** |
| 强哥变普通话 | @音频1 补 **成都温江四川话** · 加 **强哥口播：四川话男声** · 写 **禁止普通话念稿** · 重出 |
| 李阿姨变强哥声线 | 李阿姨 **独立女声** · @音频1 仅锁强哥段 |
| 李阿姨入画 | 写 **李阿姨永不出画** · 重出 |
| 报项不指橱柜台面油烟机 | 4.50～6.70s 补 **拍柜门 / 抚台面边 / 指灶上烟机** · 分 beat 重写 |
| 报项全程盯镜不指区 | 2.0～4.5s 可扫墙地 · **4.5～6.7s 必须随词指区** |
| 口播超时 | 已 **91字**；仍超时则报项句拆 beat 或压「就按说好的价做」 |
| Logo 糊/缺字 | 重写 @图片3 绑定 · 左胸「大改造家」可读 |
| 手持却推近 | 删推近/拉远 · **微晃 + 机位固定** |
| 三脚架广告感 | 总述补 **手持微晃呼吸感** · 禁止三脚架 |
