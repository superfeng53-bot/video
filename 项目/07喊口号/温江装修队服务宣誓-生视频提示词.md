### 呈现感觉（`[H]` · 气势与声音 · 写进下方可复制块）

- **整体气势**：温江室外街景自然光下，装修队团队服务品质宣誓——问—答齐声，洪亮带劲、有宣誓感，像一群兄弟拍胸立誓，不是软绵绵聊天。
- **强哥声音**：四川话领读，短促有力、起势干脆；「我们的口号是」「我们的承诺是」像发令；「只要是温江的朋友」半侧包容、语气放缓但仍有底气。
- **员工齐声**：十人同声同调、嘴型整齐，声线比强哥更齐更响；说到「全包」加重拍左胸；说到「评论或私信」「上门量房」干脆利落，有回应领读的呼应感。
- **画面配合**：全员原地定站，上半身手势放大气势；强哥前指 → 十人举拳 → 拍胸 → 齐指 → 量房请手势，动作与声音节拍对齐。

## 五、翻车修复


| 现象             | 处理                               |
| -------------- | -------------------------------- |
| 口播超 15s        | 先量配音时长；节拍 6 齐声略提速；仍超时见 [完整方案](./温江装修队服务宣誓-完整方案.md) §0.2    |
| 强哥代喊员工长句       | 写明节拍 2/4/6 十员工对口型；员工句单独录齐声轨混音    |
| **十员工变成强哥脸**   | Mixed4 **仅**绑强哥；重出故事板 CAST LOCK  |
| **员工齐声像强哥一个人** | Mixed1 只挂强哥句；员工单独齐声轨后期叠，禁止复刻强哥音色 |
| 气势软、像聊天        | 可复制块补「【气势与声音】」段；员工齐声加重、拍胸同拍      |
| 队形太整齐像方阵       | 故事板写明半弧松散定站                      |
| 十人嘴型不同步        | locked + long lens；写明齐声对口型       |
| 变成室内或队伍行走      | @室外街景背景锚点图 重出；提示词写明原位定站          |
| 变脸/变胖          | @强哥人物板 仅用于强哥段；减运镜幅度              |
| 变成普通话          | @强哥配音 为唯一音频基准                    |
| 出现字幕 / 花字      | 可复制块【执行禁止】已声明；重出                 |
| 出现背景音乐         | 可复制块【执行禁止】已声明；后期只留口播人声           |
| 全程不眨眼          | 薄层补「自然眨眼、面部肌肉放松、胸口随呼吸起伏」         |
