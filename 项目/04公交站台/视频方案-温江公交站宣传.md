## 七、15 秒节奏执行要点

**台词 10 节拍**（口型对齐）不变；**故事板 3×2 / 6 语义镜头**按戏剧段落切：第 1 行 3 格（出名指广告 / 信任背书 / 两项服务）→ 第 2 行 3 格（阳台有需要 / CTA / 落版）。

| 节奏点 | 执行 |
| --- | --- |
| 故事板布局 | **仅限 3×2、4×2、4×3**；本片定稿 **3×2**，6 格满铺无空位 |
| 开头钩子 | 0 秒第一帧已在开讲；格 1 缓推，节拍 2 必须侧身指广告，禁止指镜头 |
| 切镜原则 | 全片 **5 次硬切**（格 2～6 各一切），格 1 不切；格序 = 镜头序 |
| 核心动作 | 节拍 2「宣传」= 侧身指广告，与嘴型同步，全片最重要手势 |
| 三项服务 | 5～7 拍各一短手势，可同镜完成，禁止拖长 |
| 群众 | **全程无群众**，禁止 AI 自动生成路人 |
| 字幕/口型 | 台词一字不改，四川话口型优先 |
| 收口节奏 | 「评论区留言私信」短促，「弄巴适」留最后 0.5s 情绪尾音 |

压缩原则：

1. 可以压缩动作过程，但不能改变台词顺序。
2. 可以加快语义段之间的硬切，但不能在词组级硬切。
3. 不能减少公交站广告可读性（两行文案 + logo 必须全程可辨）。
4. 节拍 2 侧身指广告不可删、不可改成指地面或指镜头。

**绝不删**：温江、出名、公交站、宣传、9成、大哥大姐、满意、墙面翻新、厨卫改造、阳台改造、评论区留言、私信、弄巴适
