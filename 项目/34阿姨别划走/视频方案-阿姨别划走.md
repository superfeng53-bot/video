### §1.5 商业片台面抚摩技法（镜头 3 必遵）

| 技法 | 执行 |
| --- | --- |
| **跟手横移** | 手掌抚摩台面时，摄影机**平行横移跟拍**，焦点锁指尖接触区 |
| **宁慢勿快** | 抚摩慢而匀，禁止快扫甩镜 |
| **掌面抚摩** | 指腹—掌根顺势慢抹，展示石英石质感 |
| **略俯展示角** | 平视略俯 10～15°，台面占画面 60% 以上 |
