## [H] 逐轨验收

- [ ] 业主/配角明文定妆 · **不上传人物图** · 每轨交付块自写定妆
- [ ] **同场景独立** · 无末帧首帧槽 · 无「作为首帧」
- [ ] @图片3 含「大改造家」+ **仅强哥穿着**；业主家常衣
- [ ] 口播字数/时长合规；零叠说；动作窗已先扣
- [ ] 强哥口播轨：@音频1 + 四川话标
- [ ] 可复制块无 meta；末行三禁；人数正向点名

## [H] 翻车修复

| 现象 | 处理 |
| --- | --- |
| 业主挂了人物参考图 | 删业主 `@图片` · 改明文定妆 · **永不上传** |
| 业主穿成工服 / Logo 扩散 | 业主写 **家常衣** · @图片3 写死 **仅强哥穿着** |
| 强哥变普通话 | 重挂 @音频1 · 禁止普通话念稿 |
| 误用末帧作首帧 / 要求构图连续 | 删 `@图片N 作为首帧` · 只共享同场景 `@图片1` · 各轨独立明文定妆 |
