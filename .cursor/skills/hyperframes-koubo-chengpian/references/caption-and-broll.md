# 字幕断句与 B-roll 匹配（按需读）

何时再读：要改断句词表、加「禁止拆开」词、或扩展 B-roll 语义表时。

## 禁止拆开的常见词（中文口播）

断行时整词保留：

`公司` `一直` `提前` `设计师` `墙体` `结构` `预算` `改造` `开工` `口碑` `空鼓` `基层` `水管` `接线` `合同` `报价` `隐患` `勘验` `评估` `风险` `范围` `30%以上` `28%` `72%`

宁可一行 8 字，也不要留下单字残行（如单独「上」「你」「价」），除非该字本身是完整语义（少见）。

## 推荐断句形态（口播转化）

- 钩子：`为啥子六成` / `旧房改造` / `到最后都要` / `超预算` / `30%以上`
- 列举隐患：各占一行 — `空鼓基层` / `锈水管` / `乱接线` / `砸开才看到`
- 因果收束：`这些暗藏的坑` / `才是预算` / `遭不住的` / `真正原因`
- CTA：`评论区留下` / `你房子的` / `地址和面积` → `我安排金牌` / `设计师` / …

## 时间窗挂载

1. 对当前 `vo.wav` 取 segment 边界（ASR 或 silencedetect）。
2. 把语义行列表按旁白顺序装入窗口；**跳过段直接不装行**。
3. 窗内按字数比例分配 start/end；`end-start < 0.30` 则抬到 0.30（不越出窗太多）。
4. 去重叠：后条 `start` ≥ 前条 `end`。
