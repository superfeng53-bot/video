# 结尾重点展示型字幕（标准）

参考来源：`旧房换新` 业务重点文案 + 本片用户多轮确认版（最终 **18%**）。

## 何时用

口播片尾 CTA、区域+业务导流、需要「一眼记住」的收束信息。不要替代逐句口播字幕；可与底部口播字幕并存（重点在上 18%，口播在下三分）。

## 版式硬规则（用户确认）

1. **位置**：画面高度 **18%**（`top ≈ 1920 × 0.18 = 346px` @1080×1920）。
   - 太低会挡脸；太高（如 48px / 十分之八反直觉）会空顶。以抽帧不挡脸为准微调。
2. **两行结构**：
   - 上行：区域/铺垫（强调色 `#FFD166`，约 **70px**）
   - 下行：业务主卖点（**更大**，白字重描边，约 **84px**）
3. **左右留白**：`left/right ≥ 80px`，禁止左右抵满；长行先删字或缩字号，禁止横向压扁。
4. **颜色差**：上行金、下行白 + 黑描边；可加轻微金色光晕，勿堆叠多色描边。
5. **时长**：自 CTA/片尾意图开始，接到成片结束；弹入约 0.25–0.3s（`back.out`），硬切或极短淡出。
6. **字族**：本机 CJK（PingFang / Hiragino），不拉 Google Fonts。
7. **GSAP**：只动 `opacity` / `y` / `scale`；**禁止**对 `.clip` 元素动画 `visibility`（框架自管，会触发 StaticGuard）。

## 本片确认文案

```text
温江 郫县 崇州 双流 青羊
旧房翻新 厨卫局改
```

## HTML 骨架

```html
<div id="end-focus" class="clip end-focus" data-start="…" data-duration="…" data-track-index="30">
  <div class="end-focus__line1">温江 郫县 崇州 双流 青羊</div>
  <div class="end-focus__line2">旧房翻新 厨卫局改</div>
</div>
```

CSS 关键：`.end-focus { top:346px; left/right:80px }` / `__line1`（70px 金） / `__line2`（84px 白）。
